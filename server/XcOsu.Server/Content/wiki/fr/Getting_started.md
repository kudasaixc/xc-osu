# Premiers pas

xc-osu! est le client lazer qui tourne dans ton navigateur. Cette page t'emmène de l'ouverture du site à ta première partie.

## Ce qu'il te faut

- Un ordinateur avec une carte graphique, ou un circuit graphique intégré, de ces dernières années.
- Un navigateur récent. Chrome, Edge, Brave et Opera sont les mieux testés. Firefox fonctionne. Safari et les téléphones sont expérimentaux.
- **L'accélération matérielle activée** dans le navigateur. Sans elle, le jeu est dessiné par le processeur et il est trop lent pour être jouable. Le launcher te prévient quand c'est le cas ; voir [Performances](/wiki/Performance).
- Environ 1 Go d'espace disque libre pour le cache du navigateur et tes beatmaps.

## Premier lancement

La première visite télécharge le moteur, qui est gros. Laisse l'onglet ouvert jusqu'à la fin. Les visites suivantes démarrent depuis le cache du navigateur.

Pendant le téléchargement, tu vois le launcher : les nouvelles, l'état du portage et les options. Aucune option n'a besoin d'être modifiée pour commencer.

## Créer un compte

On peut jouer sans compte, mais les scores ne sont enregistrés en ligne qu'avec un compte. Dans le menu principal du jeu, ouvre le panneau du compte en haut à droite et choisis de t'inscrire. Les comptes sont propres à xc-osu! : un compte du jeu officiel ne fonctionne pas ici, et rien de ce que tu fais ici n'est envoyé là-bas.

## Récupérer des beatmaps

Ouvre la liste des beatmaps depuis le menu principal, cherche, et clique sur une beatmap pour la télécharger. Tu peux aussi déposer un fichier `.osz` sur la page. Plus de détails sur la page [Beatmaps](/wiki/Beatmaps).

## Où sont tes données

Les beatmaps, les skins et les réglages sont enregistrés par ton navigateur, sur ton ordinateur, pour ce site uniquement. Si tu effaces les données du site, si tu utilises une fenêtre privée ou si tu changes de navigateur, ils n'y sont plus. Ton compte, tes scores et ton rang sont sur le serveur et te suivent partout.
