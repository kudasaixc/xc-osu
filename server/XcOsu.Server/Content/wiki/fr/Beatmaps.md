# Beatmaps

## Récupérer des beatmaps depuis le jeu

Ouvre la liste des beatmaps depuis le menu principal. Tape pour chercher, choisis un statut et un tri, puis clique sur le bouton de téléchargement d'une beatmap. Elle est importée dès la fin du téléchargement.

La recherche comprend des filtres :

| Filtre | Signification |
|---|---|
| `stars>=6` | Au moins 6 étoiles |
| `ar>9` | Approach rate supérieur à 9 |
| `length<3m` | Moins de trois minutes |
| `bpm>=180` | 180 BPM ou plus |
| `status=ranked` | Seulement les beatmaps classées |
| `creator=nom` | De ce mappeur |
| `"phrase exacte"` | Les mots ensemble, dans cet ordre |

## Depuis le site

Chaque page de beatmap du [site](https://osu.xcsoftworks.com/web/beatmapsets) a un bouton de téléchargement du fichier `.osz`. Dépose ce fichier sur la page du jeu pour l'importer.

## Importer tes propres fichiers

Dépose des fichiers `.osz` (beatmaps), `.osk` (skins) ou `.osr` (replays) n'importe où sur la page du jeu.

## D'où viennent les beatmaps

xc-osu! n'héberge pas les fichiers de beatmaps. Ils sont récupérés sur des miroirs publics. Si un miroir est en panne, le jeu en essaie un autre : un téléchargement qui échoue une fois mérite d'être retenté une minute plus tard.

## Quelles beatmaps donnent des pp

Les scores sont enregistrés sur toute beatmap que le serveur sait identifier. Les points de performance sont accordés sur les beatmaps classées et approuvées, comme d'habitude.

## Stockage

Les beatmaps sont conservées dans le stockage du navigateur pour ce site. Un navigateur peut vider le stockage d'un site quand le disque est presque plein. Pour libérer de la place toi-même, supprime des beatmaps depuis la sélection de musiques du jeu.
