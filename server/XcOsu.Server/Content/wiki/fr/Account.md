# Ton compte

## En créer un

Inscris-toi depuis le panneau du compte dans le jeu, ou sur le [site](https://osu.xcsoftworks.com/web/register). Il te faut un nom d'utilisateur, une adresse e-mail et un mot de passe. Le même compte sert dans le jeu et sur le site.

## Modifier ton profil

Ouvre les [réglages du compte](https://osu.xcsoftworks.com/web/home/account/edit) sur le site. Tu peux changer :

- ton avatar et ta bannière (PNG, JPEG, GIF ou WebP) ;
- ton pays, ta localisation, tes centres d'intérêt, ton occupation et tes liens ;
- ton style de jeu (souris, clavier, tablette, tactile) ;
- le texte de ta page de profil, avec une mise en forme simple : titres, gras, italique, listes, liens, images, tableaux ;
- ton mode de jeu par défaut ;
- ton mot de passe.

## Connexion et déconnexion

La connexion sur le site et celle dans le jeu sont indépendantes. Se déconnecter de l'un laisse l'autre connecté.

## Mot de passe oublié

Ouvre [Mot de passe oublié ?](https://osu.xcsoftworks.com/web/home/password-reset) et indique l’adresse e-mail de ton compte. Le lien envoyé est valable 25 minutes et une seule fois. Vérifie les indésirables. Après réinitialisation, reconnecte-toi sur le site et dans le jeu : les anciennes sessions sont révoquées. Si la récupération par e-mail est indisponible, la page l’indique ; consulte [Signaler un problème](/wiki/Reporting_a_problem).

## Amis

Ajoute un ami depuis son profil, dans le jeu ou sur le site. Ta liste d'amis est commune aux deux.

## BBCode

La page me! en jeu prend en charge `[b]gras[/b]`, `[i]italique[/i]`, `[u]souligné[/u]`, `[s]barré[/s]`, `[color=#ff66aa]couleur[/color]`, `[size=20]taille[/size]`, `[url=https://example.com]lien[/url]` et `[img]https://example.com/image.png[/img]`. Markdown reste pris en charge. Les balises inconnues ou non fermées restent en texte brut.
