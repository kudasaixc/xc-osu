# Controls

The game's own key bindings are the same as on desktop and can be changed in its settings. This page covers what is different in a browser.

## Fullscreen

- `F11` or `Alt+Enter` toggles fullscreen.
- In Chrome and other Chromium browsers, `Escape` is delivered to the game while in fullscreen. **Hold** `Escape` to leave fullscreen.
- In Firefox and Safari, `Escape` always leaves fullscreen. That is a browser limitation.

## Mouse

During gameplay and in fullscreen, the game captures the mouse so the cursor cannot leave the playfield. In windowed menus the cursor moves freely in and out of the game.

If you use raw input or high sensitivity settings, set them in the game's mouse settings as you would on desktop.

## Keys that the browser keeps for itself

Some shortcuts belong to the browser or the operating system and never reach the game: `Ctrl+W`, `Ctrl+T`, `Ctrl+N`, `Alt+F4`, `Alt+Tab`. Avoid binding game actions to them. Playing in fullscreen reduces the risk of closing the tab by accident.

When you switch to another window while holding a key, the game releases every held key so nothing stays stuck.

## Tablets

A drawing tablet works as a pen through the browser, with the area and mapping set in your tablet driver. The game's own tablet area settings need direct access to the device, which is not available yet.

## Touch screens and gamepads

Both are handled, and have been tested on fewer devices than keyboard and mouse.
